# Fibonacci Calculator

A Python program for exploring Fibonacci numbers and some of their mathematical properties.

## Features

- Calculate the nth Fibonacci number
- Generate Fibonacci sequences
- Check whether a number is a Fibonacci number
- Find the index of a Fibonacci number
- Calculate Fibonacci sums
- Calculate sums of Fibonacci numbers squared
- Check divisibility between Fibonacci numbers
- Calculate Fibonacci numbers modulo m
- Verify Cassini's Identity
- Calculate Fibonacci numbers using Fast Doubling
